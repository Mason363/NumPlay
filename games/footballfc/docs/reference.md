# Visual reference

Inspected on 2026-10-23:
[Élite Foot 26](https://jeux.w-production.fr/#/jeu/elitefoot26).
Only the rendered public page and its five displayed screenshots were consulted.
No original app, binary, source or hidden game data was retrieved.

Observed images:

1. France versus Brazil, elevated perspective pitch, small footballers,
   player name, score/clock in the top left, stamina and minimap below.
2. A free-kick scene inside a stadium, direction arrow and power controls.
3. A stadium title screen, a large footballer, gold title and an OK prompt.
4. Friendly match, Career, World Cup, Penalties, Settings, Controls and Quit.
5. Side-by-side team selection, flags, attack/midfield/defense ratings,
   formation and kit details.

The public description advertises eleven-a-side matches, three difficulty
levels, fouls and free kicks, sprint stamina, career income, contracts, coach
upgrades and persistent career progress. Football FC recreates those broad
systems using its own code, team data, progression and procedural graphics.

The source does not reveal physics, AI decisions, exact controls beyond the
short public key list, league structure or contract prices. None of those are
presented as measured or extracted values in this adaptation.
