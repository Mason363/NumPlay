# pdf.js, in NumPlay Studio

`pdf.min.mjs` and `pdf.worker.min.mjs` are Mozilla's [pdf.js](https://github.com/mozilla/pdf.js), unmodified, from
the npm package `pdfjs-dist` 6.5.438. NumPlay Studio loads them only when a PDF is added, to draw its pages for
NumView (`media.js`). pdf.js is under the Apache License 2.0 ([LICENSES/Apache-2.0-pdf.js.txt](../../LICENSES/Apache-2.0-pdf.js.txt)).
