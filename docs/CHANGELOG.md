# TwiliPlay changelog

## 0.2.0 Starlight Edition

TwiliPlay now includes 25 games on the NumWorks N0120. The launcher adds a game library, three color themes, a skippable startup splash and a persistent Animations setting. Turning animations off skips the splash and makes card navigation immediate. Existing game saves are preserved.

The N0120 build installs as 2,319,740 bytes. Its launcher occupies 50,795 bytes and its maximum app RAM requirement is 133,384 bytes. The owner tested the splash and animation setting on a physical N0120.

## 0.1.0 Foundation

Added an ordered 18-game N0120 build, installer-based flash and RAM gates, and per-game ARM emulator launch checks. Doodle Jump is included with its original recovery script. See the [Foundation build and test report](foundation.md).
